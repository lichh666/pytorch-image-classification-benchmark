# Provenance and publication scope

Dependencies retain their respective licenses. Dataset access and use remain subject to the original provider terms; no dataset redistribution license is granted here. No new blanket open-source license has been assigned pending the owner's licensing decision. See `provenance.json` for source and curated-file hashes.
